## 0. One paragraph
Three small, independent pieces. **F1** makes reconciliation compare quantities, not just contract presence, and — for single-leg positions only, after the same mismatch is seen twice ≥ 30 s apart — corrects the ledger to the broker's quantity with a synthetic fill, so the decision model and the ledger-driven 15:50 flatten see the true position. **F2** adds trade-quality statistics (win rate, profit factor, expectancy, drawdown) to the 16:10 digest and a new `/dpof stats`. **F3** is an offline research script measuring what the underlying did 5/15/30/60 minutes after composite threshold crossings. F1 changes ledger bookkeeping only (never places, sizes or cancels an order); F2 and F3 are read-only.

## 3. F1 — Reconcile quantity check + single-leg ledger correction (`orders.py`, `engine.py`, `config.py`)
### 3.1 `recompute_from_fills` (pure)
- `entry_filled` = Σ `filled_qty` over purpose `"entry"` **and** `"reconcile_add"`; `exited` = Σ over `"exit"` **and** `"reconcile_remove"`; `qty_open = max(0, entry_filled − exited)`.
- `entry_price` = qty-weighted avg over fills with a known `avg` among purpose `"entry"` only (synthetic fills have `avg=None` and never enter the weighting). None if no priced entry fill.
- `realized_pnl` = unchanged formula over purpose `"exit"` fills only.
- **Every other `order_fills` consumer stays purpose `"exit"`-only** (`close_position` baseline, `_work_exit`/`_exit_missing_or_wait`/`_advance_exit` batch math, `_exit_fills_in_current_batch`, `_batch_realized_pnl`) — do NOT widen them; add tests proving a synthetic fill leaves batch math unchanged.
### 3.2 `OrderManager.reconcile(now_epoch: Optional[float] = None) -> list[str]`
Keep the existing broker-unavailable, in-flight skip, `reconciled_absent` and orphan behavior **byte-for-byte in effect**. Add, after them:
1. `broker_qty[symbol]` = signed int from `list_option_positions()`. `ledger_qty[symbol]` = Σ over ledger positions with status `open`/`closing` of `qty_open × leg.ratio_qty × (+1 if leg.side == "buy" else −1)` for each leg.
2. For each symbol present on BOTH sides (non-zero) with `ledger_qty != broker_qty`: skip (no warning, clear any pending entry) only while the manager is still working it — any holding position not `status == "open"` (pending/closing) or with `cancel_requested`; those states end on their own. Otherwise append warning `qty_mismatch:{symbol}:ledger={l}:broker={b}` — an `open` position is never silent. *(Pass-2 fix: the first build also skipped when any chain cid lacked an `order_fills` entry; a cid the broker never received stays in the chain with no entry after a 404-resend, which silenced the check for that position forever.)*
3. **Adopt-eligible** only if `cfg.reconcile_adopt_qty` and exactly one ledger position holds the symbol and that position has `structure == "single"`, exactly one leg, `side == "buy"`, `ratio_qty == 1`, `broker_qty > 0`, and no chain cid has a RECORDED non-terminal status (a cid with no `order_fills` entry never reached the broker and is ignored).
4. Pending/confirm state (in memory, `self._pending_qty_mismatch: dict[symbol, {"ledger": l, "broker": b, "first_seen": t}]`): first sighting → record, no change. Later sighting with the SAME `(l, b)` and `now − first_seen ≥ cfg.reconcile_confirm_seconds` → adopt. Different `(l, b)` → replace with the new sighting. A symbol no longer mismatched (or no longer eligible) → drop its pending entry. A restart loses pending state (it only delays).
5. **Adopt**: `delta = b − l`; key `f"reconcile:{int(now)}:{symbol}"` (unique; if taken, append a counter); `pos.order_fills[key] = {"purpose": "reconcile_add" if delta > 0 else "reconcile_remove", "filled_qty": abs(delta), "avg": None, "status": "reconciled", "broker_qty": b, "ledger_qty": l, "at": now}`; `self._apply_recompute(pos, now)`; `await asyncio.shield(self._ledger.upsert(pos))`; `logger.warning(...)`; append warning `qty_adopted:{pos.id}:{symbol}:{l}->{b}`; drop the pending entry. Never touches `qty_original`, `status`, `exit_reason`, orders.
6. New public `has_pending_qty_mismatch() -> bool`.
### 3.3 Engine
Step 8c condition becomes `is_tenth_cycle or self._orders.has_pending_qty_mismatch()` and passes `now` into `reconcile(now_epoch=now)`. Nothing else in the engine changes. Existing alert text/dedupe (`[RECONCILE] DPOF {w}`, key per warning string, 86,400 s) carries the new warnings.
### 3.4 Config (dataclass default == `load_dpof_config` default; `validate()`)
`reconcile_adopt_qty: bool = True` (`CLIO_DPOF_RECONCILE_ADOPT`); `reconcile_confirm_seconds: float = 30.0` (`CLIO_DPOF_RECONCILE_CONFIRM_SECONDS`, must be ≥ 0). `.env.template` entries.
### 3.5 Tests (`tests/dpof/test_reconcile_qty.py`, fakes only)
Surplus and deficit both adopted after confirmation only; first sighting changes nothing; changed quantities reset the clock; no adopt with a non-terminal/missing chain order, `closing`, `cancel_requested`, two positions on one symbol, a debit vertical, a sell leg, negative broker qty, or knob off (warnings still emitted); `recompute_from_fills` counts synthetic fills and keeps `entry_price` from real fills; after a surplus adopt, `close_position(qty=new qty_open)` is accepted and a partial exit's batch math / `_batch_realized_pnl` are unchanged by the synthetic entry; `reconciled_absent`, orphan and broker-unavailable behavior unchanged; engine runs reconcile on a non-tenth cycle while a mismatch is pending.

## 4. F2 — Trade-quality statistics (`agent/dpof/trade_stats.py` new, `readmodel.py`, `telegram_commands.py`)
### 4.1 Pure module `trade_stats.py` (stdlib only; textbook formulas, no third-party code)
- `is_real_trade(pos) -> bool`: `status == "closed"`, `qty_original > 0`, `entry_price is not None`, `closed_time is not None`, `exit_reason` not in `("log_only", "submit_unconfirmed", "reconciled_absent")` and not starting `"submit_failed:"` (same sets as `reflection.py:78-79`; a test asserts parity with those constants).
- `pnl_incomplete(pos) -> bool`: any `order_fills` value whose purpose is in `models.RECONCILE_FILL_PURPOSES`.
- `compute_trade_stats(positions) -> dict` over real trades, P&L-complete ones only for $ stats: `n`, `wins` (`realized_pnl > 0`), `losses` (`< 0`), `scratches` (`== 0`), `win_rate` (wins / (wins + losses); None if both 0), `net_pnl`, `avg_win`, `avg_loss` (None when empty), `profit_factor` = gross win / |gross loss| (**None when there are no losses — never inf**, anti-pattern #1), `expectancy` = net_pnl / n_complete, `best`, `worst`, `max_drawdown` = largest peak-to-trough fall of cumulative realized P&L ordered by `closed_time` (starting from 0; 0.0 only when there is at least one complete trade and no fall), `incomplete` = count excluded for `pnl_incomplete`. Every numeric field is None when its inputs are empty (no fake zeros).
- `render_trade_stats(label, stats) -> str`: compact plain-text lines, e.g. `Trades today: 4 (3W 1L) | win 75% | net +$212 | PF 3.4 | exp +$53/trade | avg W +$96 L −$76 | maxDD −$76` and `(1 excluded: P&L incomplete after reconcile)` when relevant; `n/a` for None.
### 4.2 Windows (R4)
**Today** (ET day, `closed_time` within the ET day) and **all history** (label `since <first ET date>`). All history = `positions.json` (via `load_positions`) + `positions_archive.jsonl` (new `readmodel.load_archived_positions(ddir)`: streaming line read, `PositionRecord.from_dict` per line, unparsable/idless lines skipped, never raises), merged by id with the `positions.json` record winning.
### 4.3 Read model + surfaces
- `readmodel.trade_stats_text(ddir=None, now_epoch=None) -> str` — never raises; today + all history.
- `eod_digest_text`: new "Trades" section (today + all history) inserted right after the Entries/Nominations counts line; its own try/except → one `Trades: unavailable` line, so it can never fail the digest. The digest's existing no-signal-cycles early return stays as is. The digest already runs in an executor (`scheduled_tasks.py:1773`), so the archive read is off-loop.
- `/dpof stats` in `telegram_commands.py` (one `elif`, lazy import, `run_in_executor`, usage string updated).
### 4.4 Tests (`tests/dpof/test_trade_stats.py`)
Formulas on hand-computed fixtures; no-loss → PF None; empty → all None; scratches; drawdown ordering by `closed_time`; exclusion of every non-real exit reason and unfilled entries; incomplete positions excluded from $ stats and counted; parity with reflection's constants; digest contains the section and survives a corrupt `positions.json`; `/dpof stats` dispatch.

## 5. F3 — Offline signal study (`scripts/dpof_signal_study.py` new; tests)
**Never imported by `agent/`; writes nothing unless the operator passes an output path; stdlib only (no pandas; numpy not needed).**
### 5.1 Inputs
- `--signals PATH` (default: `<repo>/data/dpof/signals.jsonl`; honours `CLIO_DPOF_DATA_DIR`). Record shape per `engine.py:2366-2387`: `ts` (tz-aware ET ISO), `underlying`, `composite` (float|None), `strength`, `direction` (str|None), `price_confirm {"ok": bool|None, "reasons"}`, `regime`, `flow_source`, `nominated`, `outcome`, … Records with `composite is None` are skipped (never treated as 0). The file is capped (20,000 lines, newest 90% kept on trim) — print the covered time span.
- Bars (R5): `--bars-file PATH` (JSONL `{"symbol","t" (epoch of bar START),"c"}` or CSV `symbol,t,c`), else fetch from Alpaca: `load_dotenv(<repo>/.env)` BEFORE importing `agent.*` (CLAUDE.md anti-pattern #34), keys via `agent.dpof.config.load_dpof_config()` (`alpaca_key_id`/`alpaca_secret_key`, `stock_feed`), `StockHistoricalDataClient.get_stock_bars(StockBarsRequest(symbol, TimeFrame(1, Minute), start, end, feed))` per underlying per ET day spanned, with IEX fallback on a 401/403. `--save-bars PATH` writes the fetched bars as JSONL. Never print keys.
### 5.2 Pure core (importable functions, unit-tested)
- `load_signal_records(lines) -> list[dict]` (skips bad JSON, None composite).
- `find_events(records, threshold, min_gap_minutes) -> list[Event]` (R6): per (underlying, sign(composite)) — an event at the first record with `|composite| ≥ threshold` whose previous record for that underlying had `|composite| < threshold` or the opposite sign or a gap > 5 min (a new session/restart), and no event in the same (underlying, direction) within `min_gap_minutes` before it. Event carries ts epoch, underlying, direction (+1/−1), composite, strength, `price_ok` (True/False/None), regime, flow_source, nominated.
- `price_at(bars, epoch, max_staleness_s=120) -> float|None`: close of the latest bar whose END (`t + 60`) ≤ epoch (no look-ahead), None if that bar ended more than `max_staleness_s` before epoch (covers the close, half-days and gaps without a calendar).
- `forward_returns(events, bars_by_symbol, horizons=(5, 15, 30, 60))`: `r = direction × (p(t+h) − p(t)) / p(t)` in bps; None when either price is None (counted as `no_data`, never 0).
- `summarize(rows, group_by)` per (threshold, horizon, price_ok bucket, underlying): `n`, `hit_rate` (r > 0), `mean_bps`, `median_bps`, plus a baseline row per (underlying, horizon): the long-only forward return over ALL records (market drift reference). Rows with n < 30 are marked `descriptive only (n<30)`; no p-values.
- `render_report(summary) -> str` plain text; `--json-out PATH` optional machine-readable output.
### 5.3 CLI
`python3 scripts/dpof_signal_study.py [--signals P] [--bars-file P | --save-bars P] [--thresholds 0.15,0.30] [--horizons 5,15,30,60] [--min-gap-minutes 15] [--since YYYY-MM-DD] [--until YYYY-MM-DD] [--json-out P]`. Defaults for thresholds read from `DPOFConfig` when importable, else 0.15/0.30.
### 5.4 Tests (`tests/test_dpof_signal_study.py`; synthetic data only, `tmp_path`, no network, no `data/`)
Event detection (crossing, refractory, direction flip, gap reset, None skipped); `price_at` no-look-ahead and staleness; forward returns sign and bps; None propagation; summary counts/hit rate/median; n<30 marking; CLI end-to-end on tmp files with `--bars-file` and `--json-out`; importing the module performs no I/O and no network; `grep` test that nothing under `agent/` imports it.
